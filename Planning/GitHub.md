##  Navigating the Terminal
- Accessing file:
    cd /Path/to/file
- Seeing what is in folder:
    ls
- Creating a folder:
    mkdir FolderName
- Moving a file:
    mv filename /newFolder/filename

## GitHub Commands
- Pulling from the repo (do everytime when starting work):
    git pull
- Pushing to the repo (git pull first if working at the same time as someone else):
    git add .
    git commit -m "message about what you did"
    git push
